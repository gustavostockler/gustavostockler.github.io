Excel (.xlsx / .xls) ou CSV · vários arquivos de uma vez · Balanço e DRE podem estar no mesmo arquivo (abas)

Se o arquivo tiver colunas de meses (ex.: Jan-2026, 01/2026, 2026-01) cada coluna vira uma competência. Se tiver só uma coluna de saldo (Saldo Atual, Valor…), ela é lançada na competência acima — ou no mês indicado no nome do arquivo (ex.: balancete_03-2026.xlsx). Ao anexar de novo o mesmo mês, o arquivo mais recente prevalece.

Como o arquivo é lido

  • A coluna com os nomes das contas é detectada automaticamente (códigos como 1.1.01 - são ignorados).
  • Ativo × Passivo: contas com o mesmo nome (ex.: CIRCULANTE) são separadas pela linha ATIVO/PASSIVO, pelo código da conta (1 = Ativo, 2 = Passivo, 3+ = Resultado) ou por uma coluna Seção (A / P / D).
  • Abas com nome contendo DRE ou Resultado são tratadas como DRE.
  • Números no formato brasileiro (1.234,56, (1.234,56)) são aceitos.
  • Contas de resultado (DRE) são somadas no período; contas patrimoniais usam o saldo do último mês do período.
